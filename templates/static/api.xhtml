{% trans "A Note about OAuth" %}

{% trans "NewsBlur supports OAuth but to have an OAuth enabled client you must" %} {% trans "email Samuel" %} {% trans "to request a client ID and secret. You will need to provide your NewsBlur username, redirect URI (often just your client app's website), and app name." %}

{% trans "To use OAuth when authenticating requests, be sure to pass the Bearer HTTP header with every request, just as you would on any other OAuth API. Use the" %} /oauth/authorize {% trans "endpoint to begin the OAuth authentication procedure. Use the" %} /oauth/token {% trans "endpoint to receive your authorized token, which you can pass in with every request." %}

{% trans "You are not required to use OAuth, in which case you will need to pass the" %} newsblur_sessionid {% trans "cookie with every request. This cookie is set on" %} {% trans "login" %}.
