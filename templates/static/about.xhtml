2009

{% trans "Samuel wanted a better way to read the news. So he built the first version of NewsBlur almost entirely underground on the A train in New York City." %}

2010

{% trans "NewsBlur launched to the public and to favorable reviews. Premium accounts launched in October, paying for NewsBlur's increasing server costs." %}

2012
