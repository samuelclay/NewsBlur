# NewsBlur Android 17.0

Version code 303.

NewsBlur 17 brings lively, ordered animations to feeds, folders, story titles, and articles, plus fast transitions between All, Unread, Focus, and Saved. Turn on Reduce motion in Preferences > Appearance to remove movement while keeping fades. It's off by default. Discovery tags have more room on phones, and tablet dialogs work better when rotating the screen.

Canonical notes and listing copy cover all 21 supported app languages. Publish to full production after validating the signed bundle and Play release state. The release tag must identify the exact version-bump commit. Submission status is recorded separately from build and upload status.
