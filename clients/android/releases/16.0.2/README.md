# Android16.0.2

Version16.0.2, code294 replaces the unsubmitted16.0.1 (293) draft. It includes the recovered three independent tablet fullscreen controls, saved pane widths, a quiet resize border, and the approved live-guide fallback for older Android window extensions. On those devices, the guide tracks the finger and commits the exact chosen width on release, avoiding queued native resize animations.

The16.0.1 tag and uploaded artifact remain unchanged. Play16.0 (292) is halted with15.1 (291) as fallback; this replacement is being built and has not yet been uploaded or submitted.

Canonical notes are in `clients/store/releases/16.0.2/`; Play exports are beside this README. Existing21-localization listings, purchases/subscriptions, and artwork are retained.
