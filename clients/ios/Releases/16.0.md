# NewsBlur Version 16.0 Release Notes

## Version 16.0 (build 343)

### iOS What's New

NewsBlur now speaks 21 languages. Menus, buttons, settings, and setup follow your device language, or you can choose a language in Preferences. Your stories stay exactly as published.

The language chooser previews the title, prompt, and button in the language you select, with English underneath. Arabic and Hebrew use a right-to-left interface.

Keyboard shortcuts now work while the story list has focus, and N opens the first unread story.

If a translation sounds awkward, tell us the language and where you saw it on the NewsBlur forum.

### App Review notes

Version 16.0 translates NewsBlur's interface into 21 languages, chosen automatically from the device language and changeable under Preferences > Language. On first launch in a non-English language, a one-time dialog shows the detected language beside English. Story content is not translated. Please use the existing review account credentials.
