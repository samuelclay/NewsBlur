# NewsBlur 16.2

The minor release uses iOS and macOS build 356 and Android version code 302. Release tags are `iOS_16.2_356`, `macOS_16.2_356`, and `Android_16.2_302`. The first 16.2 builds, 355 and 301 at `iOS_16.2`, `macOS_16.2` and `Android_16.2`, were uploaded but never submitted for review; the AI filter scoring change below superseded them.

## Changes

- Show matching AI content and image filters in stories and manage them in the trainer. An AI filter match scores like any other classifier: a focus match is a like, a hidden match is a dislike, a prompt that didn't match changes nothing, and Hide beats everything. The trainer legend reads Hide beats Like beats Dislike on every platform.
- Play podcasts in Listen, with skip controls, a shared podcast and narration queue, and playback position synced across devices.
- On iOS and Android, read stories over music from other apps with optional ducking and a Music / Voice balance. Podcasts retain normal audio focus. Voice previews preserve podcast focus and follow narration preferences when a podcast is paused.
- Use the smaller Listen toolbar symbol consistently on iOS and Mac.

Store notes cover all 21 languages in `clients/store/releases/16.2/`. Preserve existing listing copy, artwork, product metadata, review credentials, and country availability. Release automatically after approval.

## Validation

The release passed 1,681 Django tests, 37 Node classifier/scoring tests, 1,196 Android unit tests, and 54 focused Listen tests on each of iOS and Mac Catalyst. Release artifacts and build logs are kept under `~/Library/Caches/newsblur-release-16.2/`.

The complete iOS CI suite found a three-second UIKit presentation timeout in the existing signed-out preferences test. That fixture now uses `SimulatorTestTiming.realWorkTimeout`, consistent with the repo's other asynchronous UI tests. Mac audio tests also account for intentionally unavailable narration-mixing controls.

Build 356 and version code 302 add the AI filter scoring change. They passed the server scoring tests (29), the web scoring tests (6), the focused iOS scoring tests (6) and the full Android unit suite (1,198). Both Apple archives were exported through Xcode's signed-in account after the App Store Connect API key was refused for cloud-managed distribution signing.

All 21 localized release-note files pass store validation. Deploy both web and Celery so background scoring uses the same filter precedence. No database migrations are included. Deployment and store submission states are recorded separately after verification.
