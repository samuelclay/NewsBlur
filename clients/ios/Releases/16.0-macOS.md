[Mac App Review submission](https://appstoreconnect.apple.com/apps/463981119/distribution/reviewsubmissions/details/0c3c3b9c-dc2e-491b-baa1-74b8d9526766)

## What’s New

NewsBlur for Mac now speaks 21 languages. Choose a language from the NewsBlur menu, or follow your Mac’s language settings. Arabic and Hebrew support right-to-left layouts. Stories stay exactly as published.

Widgets now show a folder or site of your choice, with a separate selection for each widget. New widgets start with All Site Stories using your signed-in account. Refreshing is more reliable, including when hidden stories come first. Remove and re-add existing NewsBlur widgets to use the new version, then right-click and choose Edit Widget.

Clicking a story now slides to it in the correct direction. Done appears when there are no unread stories left and returns you from the feed correctly.

The sidebar has more balanced spacing and compact filters, with Add Site and Settings kept separate. Command-W closes the window while NewsBlur keeps running; click the Dock icon to reopen it. Command-Q quits the app.

Keyboard shortcuts work while the story list has focus, including N for the first unread story.

## App Review notes

Build 348 replaces build 344. Includes 21 interface languages, configurable folder/site widgets, more reliable story refresh, and Mac navigation/sidebar fixes. Sign in with the existing review account. Add a NewsBlur widget from On This Mac; it defaults to All Site Stories. Right-click the widget and choose Edit Widget to select a folder or site independently. Existing widgets must be removed and re-added. Command-W closes the window while the app stays running; the Dock icon reopens it. Command-Q quits. Choose a language from NewsBlur > Language > Choose Language. Story content is not translated.
