# NewsBlur for Mac 16.0.1

Version 16.0.1, build 349. Preparing for App Review with automatic release after approval.

- Preferences and Keyboard Shortcuts share a configurable scroll amount.
- The story settings menu can open Keyboard Shortcuts directly.
- The Mac window restores its size and position across relaunches.
- Ask AI model labels reflect the current providers.
